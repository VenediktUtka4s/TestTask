# Мини-синхронизатор заявок

**Живой сервис:** https://orders-sync-venedikt.netlify.app

Забирает «сырые» заявки с `https://test.ooobs.ru/api/orders`, нормализует телефоны, схлопывает дубли и отдаёт результат в JSON.

## Правила

- **Телефон** → `+7XXXXXXXXXX`: из строки берутся только цифры; 10 цифр — дописывается код `7`; 11 цифр с ведущей `8` — заменяется на `7`. Всё, что не даёт 11 цифр с `7` в начале, — невалидно и отбрасывается.
- **Дубли** по нормализованному телефону: остаётся запись с максимальным `amount`, при равных — более поздняя по `created_at`. Поля клиента берутся из выигравшей записи.
- **Идемпотентность**: результат — чистая функция от ответа источника, клиенты отсортированы по телефону, поэтому повторный запуск даёт тот же JSON.

## Ответ

```json
{
  "clients": [{ "name": "...", "phone": "+79991234567", "email": "...", "amount": 5000 }],
  "stats": { "received": 17, "unique": 8, "duplicates_merged": 5, "invalid_dropped": 4 }
}
```

`duplicates_merged = валидные заявки − unique`.

## Запуск

```bash
node server.js   # http://localhost:3000
```

Без зависимостей, Node.js 18+.

## Деплой

- **Netlify** — `netlify/functions/clients.mjs`, все пути переписываются на функцию в `netlify.toml`.
- **Render / любой хостинг с Node** — `npm start` (`server.js`, порт из `PORT`).
- **Vercel** — `api/clients.js` + `vercel.json`.

## Секреты

Секретов в сервисе нет: источник `/api/orders` открытый, ключи и токены не нужны, поэтому в репозитории ничего чувствительного не лежит. Адрес источника вынесен в переменную окружения `SOURCE_URL` (по умолчанию — ссылка из задания). Если появится ключ API, он пойдёт так же в переменные окружения Netlify, а не в код: тогда его можно менять без коммита, и он не попадёт в публичный репозиторий.
